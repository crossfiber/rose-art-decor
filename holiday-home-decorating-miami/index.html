Seasonal and holiday home decorating Decoración de temporada y fiestas

Rose describes herself as a tree designer for all holidays, and that is meant literally. Christmas fills the calendar, but the rest of the year is where a house stops looking like it only gets attention in December.

Every holiday, not just the big one

The same instincts that build a Christmas tree work on any occasion with a color and a mood: a birthday, a graduation, Easter, a first communion, an anniversary at home. Scale, layering and one decided palette are what separate a designed table from a bag of party supplies.

Because the work is seasonal, booking outside of November and December is far easier, and a weekday is usually available.

Seasonal refreshes for a room

A seasonal refresh is smaller than a holiday installation and it is what keeps an entry, a console or a mantel from sitting untouched for a year. Autumn tones, spring greens, a summer reset. Usually one or two surfaces, done in a single short visit.

It is also the cheapest way to find out whether you like working with a decorator before committing to a whole Christmas.

Same team, same method

Whatever the occasion, the sequence does not change: palette first, materials second, install third. You either provide what you own or we source it at the flat $50 plus cost, exactly as with the trees.

Use the quote form and pick the seasonal option, or describe the occasion in the notes. The tree size field can be skipped with a dash if there is no tree involved.
